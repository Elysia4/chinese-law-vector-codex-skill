## 一、已解决的问题

### 1. 截图里那套爬虫代码已经失效（别人给的教程）

| 项 | 内容 |
| --- | --- |
| 现象 | 网上教程用的 `POST https://flk.npc.gov.cn/api/` 与 `/api/detail` 全部返回 **405** |
| 根因 | 官网已改版成 Vue SPA，接口迁到 `/law-search/*` |
| 修法 | 新脚本走 `POST /law-search/search/list`（清单）+ `POST /law-search/download/batch`（换签名下载链接） |

### 2. 网宿 WAF 的 cookie 挑战 → 302 自指死循环

| 项 | 内容 |
| --- | --- |
| 现象 | `urllib` 报 `HTTP Error 302: The HTTP server returned a redirect error that would lead to an infinite loop` |
| 根因 | 首次请求返回 `302 Location: /同一路径` 并下发 `Set-Cookie: wzws_cid=...`（响应头带 `WZWS-RAY`），**客户端不保存 cookie 就会永远原地打转** |
| 修法 | HTTP 层挂进程级共享 `CookieJar`（`fetch_corpus._opener`） |
| ⚠️ 教训 | 我一开始**误判为本机 Clash 代理**（127.0.0.1:7897）导致，实测跳过代理直连同样复现。**先抓原始响应头再定性**，不要凭现象猜原因 |

### 3. 突发请求被 WAF 限流：HTML 挑战页被当成 JSON 解析

| 项 | 内容 |
| --- | --- |
| 现象 | 大量 `Expecting value: line 1 column 1 (char 0)`，看起来像网络故障 |
| 根因 | WAF 在请求突发时返回 **HTML 挑战页**，`json.loads` 自然失败；静默几十秒到几分钟即恢复 |
| 修法 | 新增 `AdaptiveLimiter`：被拦间隔 ×2（上限 120s）、连续 4 次被拦进入 **5 分钟长冷却**、连续 6 次成功才 ×0.7 收回、**间隔持久化**到 `downloads/.rate_state.json` 供重跑复用 |

### 4. 限流把不受保护的下拉下载也一起拖慢（性能问题）

| 项 | 内容 |
| --- | --- |
| 现象 | 2395 个文件的下载也被按 60s/个的节奏卡住，预计要跑 40 小时 |
| 根因 | 节流是**全局**的，但 WAF 只保护主站 API；签名下载链接指向 OBS 对象存储，不受限流影响 |
| 修法 | 按主机拆分节流（`THROTTLED_HOST_SUFFIX`），只对 `flk.npc.gov.cn` 生效。修完实际速度约 2.5 件/秒，2391 件约 16 分钟 |

### 5. 官方清单抓取本身太贵

| 项 | 内容 |
| --- | --- |
| 现象 | 每个类目至少抓两遍、页与页之间零间隔，几十上百个请求打出去必然触发限流 |
| 修法 | ① 单页类目（`total ≤ pageSize`）不存在分页抖动，只抓一遍；② 清单缓存到 `downloads/.official_checklist.json`（7 天有效，`--refresh-list` 强制刷新） |

### 6. 官方标题自带「（失效）」后缀 → 58 件配不上（数据缺陷）

| 项 | 内容 |
| --- | --- |
| 现象 | 58 个文件"未匹配官方条目"，只能以**状态未确认**混进 `current` 层 |
| 根因 | 官方 API 的 `title` 字段自带「（失效）」后缀，而 `split_name()` 按设计把这个标记从**文件名**里剥掉 → 两边不一致，按（标题+公布日期）配对必然落空 |
| 危害 | 已失效的文本被当成能引用的现行条文 |
| 修法 | 两侧统一剥离（`VOID_PAT`） |

### 7. 官方标题用空格、文件名用「+」→ 9 件配不上

| 项 | 内容 |
| --- | --- |
| 现象 | 「最高人民法院**空格**最高人民检察院…」（官方）vs「最高人民法院**+**最高人民检察院…」（文件名） |
| 修法 | 新增"忽略空格与顿号"的规范化键兜底匹配 |

### 8. 没有公布日期的 81 件被静默丢弃（覆盖缺陷）

| 项 | 内容 |
| --- | --- |
| 现象 | 「有关法律问题的决定」类目总数 188，语料里只有 107，一直报警"官方接口可能异常" |
| 根因 | 请求其实成功了，是 `fetch_official()` 里一句 `if title and date:` 把**没有 `gbrq` 字段的 81 件**（全国人大及其常委会的决定、决议，含《关于完善香港特别行政区选举制度的决定》）挡在语料外 |
| 修法 | 只要求有标题，日期可空；官网给这类件的文件名是 `标题_.docx`，配对逻辑本来就兼容 |
| 连带 | 修完触发 `promulgated=None` 的 `.replace()` 崩溃 → 在源头把 `gbrq` 规范化成空串 |

### 9. 构建只写不删 → 旧语料残留

| 项 | 内容 |
| --- | --- |
| 现象 | 重建后磁盘 2487 个文件、清单 2476 条，多出 11 个 |
| 根因 | 改了类目归属（如 9 件联合司法解释过去因配对失败被塞进「高法司法解释」）后，旧文件留在盘上变成**重复条目** |
| 修法 | 构建收尾加清理：只清 `corpus/<类目>/` 下不在本次清单里的 `.md`，并回收空目录 |

### 10. 其他小 bug

| 问题 | 修法 |
| --- | --- |
| `merge_zip` 未建父目录 → `FileNotFoundError` | 写 zip 前 `mkdir(parents=True)` |
| `official_filename` 内网兜底分支取错变量（从 `url` 而非 `urlIn` 找 `fileName`）→ 永远解析不到文件名 | 改为查 `urlIn` |
| 地方法规属地取不到（列表接口对市级机关一律返回 `zdjgCodeId=9999`） | 改为**从制定机关名提取属地**（"湘潭市人民代表大会常务委员会"→"湘潭市"），反而让"用户说地名就能匹配"更直接 |
| 沙箱环境：python 走本机代理返回 302 自指（环境问题，非站点） | node/undici 不受影响；抓取脚本按主机绕过代理 |

### 11. 仍未根治的已知限制

- **分页抖动**：地方性法规抓到 23454/23475（少 21 条），国家级"行政法规"也曾出现 832/833。缓存与去重能减轻，但彻底解决要靠二次补抓。
- 地方法规元数据**只有标题**：官方接口本身也只支持标题检索（"押金"全库 total=0，文内检索接口 `highSearch` 各种入参都是 500）。所以地方这一层靠"地域 + 主题词扩展"，不是纯语义。
