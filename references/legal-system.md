# 法律效力与适用规则

本文档在遇到法律冲突、新旧衔接、溯及力、版本确认问题时阅读。文中条文号均已对照 `corpus/` 中的现行文本，可直接引用。

## 一、效力位阶

从高到低：《宪法》→ 法律（全国人大及其常委会）→ 行政法规（国务院）→ 地方性法规 → 地方政府规章。

- 《中华人民共和国宪法》第五条：一切法律、行政法规和地方性法规都不得同宪法相抵触。
- 《中华人民共和国立法法》第九十八条：宪法具有最高的法律效力，一切法律、行政法规、地方性法规、自治条例和单行条例、规章都不得同宪法相抵触。
- 《中华人民共和国立法法》第九十九条：法律的效力高于行政法规、地方性法规、规章；行政法规的效力高于地方性法规、规章。
- 《中华人民共和国立法法》第一百条：地方性法规的效力高于本级和下级地方政府规章。

**本语料收录到"行政法规"这一层为止**：宪法、法律、法律解释、有关法律问题的决定、行政法规、监察法规、司法解释（高法/高检/联合发布）都有全文。**不含**部门规章、地方性法规、自治条例与单行条例、经济特区法规、地方政府规章——问题落在这些范围时要说明语料未收录、需另行核实，不要用位阶相近的条文替代。

引用位阶关系时注意：司法解释的效力低于法律和行政法规，是"对法律的解释"而非立法；地方性法规在本地适用但不适用于全国。

## 二、同一事项出现多个规定时的适用顺序

《中华人民共和国立法法》第一百零三条：同一机关制定的法律、行政法规、地方性法规、自治条例和单行条例、规章，特别规定与一般规定不一致的，适用特别规定；新的规定与旧的规定不一致的，适用新的规定。

据此，判断顺序为：

1. 先看是否属于特别法（如《消费者权益保护法》相对于《民法典》的一般规定）；
2. 同一位阶下新法优于旧法；
3. 仍不能确定时，依《立法法》第一百零五条、第一百零六条由制定机关或全国人大常委会裁决——这类争议不能凭推定了结。

## 三、时间效力

《中华人民共和国立法法》第一百零四条：法律、行政法规、地方性法规、自治条例和单行条例、规章不溯及既往，但为了更好地保护公民、法人和其他组织的权利和利益而作的特别规定除外。

实务要点：

- **公布日 ≠ 施行日**。语料 frontmatter 中 `promulgated` 是公布日，`effective` 是施行日。行为发生在施行日之前的，原则上适用当时有效的旧法。
- **`status` 为"尚未生效"** 的法律只能作为将来规定引用。
- **修正与修订不同**：修正通常只改动个别条文并公布修正案或修改决定；修订往往重新公布全文并另定施行日。以语料中的最新文本为准，并核对 flk 上的沿革信息。
- **法典化带来的废止**：《中华人民共和国民法典》第一千二百六十条明定自 2021 年 1 月 1 日起施行，同时废止婚姻法、继承法、民法通则、收养法、担保法、合同法、物权法、侵权责任法、民法总则。涉及这些领域的旧案与旧文引用，必须改引《民法典》对应编章。
- **法典化的第二例**：《中华人民共和国生态环境法典》第一千二百四十二条规定自 2026 年 8 月 15 日起施行，同时废止环境保护法、环境影响评价法、海洋环境保护法、大气污染防治法、水污染防治法、土壤污染防治法、固体废物污染环境防治法、噪声污染防治法、放射性污染防治法、清洁生产促进法。问及这些单行法时，一律改引法典相应编章。
- **判断某部单行法是否仍有效**，看 flk 的现行有效清单或语料目录，不要依赖记忆中的"这部法律当然还有效"。
- **司法解释的时间效力**（如最高人民法院关于民法典时间效力的规定）不在语料内，涉及新旧衔接的具体案件时需单独核实。

## 四、引用格式

- 层级顺序固定：条 → 款 → 项 → 目。款用"第X款"，项用"第（X）项"，写作《中华人民共和国刑法》第六十七条第三款、第（二）项。
- 法律名称首次出现用全称《中华人民共和国XX法》，同一段落内再次出现可用简称。
- 不要写成"公司法第 88 条"这类混合形式；中文条号用汉字（第八十八条）。
- 引用司法解释需写全称与法释文号；司法解释不在本语料内。
- 引用时同步给出结论所依赖的版本与施行日期，方便对方核对。

## 五、常见错误清单

1. **引用已被取代的文本**：合同法、物权法、婚姻法、继承法、担保法、侵权责任法、民法总则自 2021-01-01 起废止，改引《民法典》。
2. **忽略"应当"与"可以"的区别**：前者是义务性规定，后者是授权性规定。
3. **忽略本数规则**：《中华人民共和国刑法》第九十九条规定，本法所称以上、以下、以内，包括本数。其他法律中的"以上/以下"一般也包含本数，但仍应以该法自身规定为准。
4. **只看一款**：一款常含多种情形或例外（如"但是"后的除外条款），引用前读完整个条文。
5. **误把规章当法律**：部门规章、地方政府规章、规范性文件不是"法律"，效力位阶和处罚设定权限都不同。
6. **把草案、征求意见稿当作现行法**：以 flk 上已公布的正式文本为准。
7. **条文号记忆偏差**：不要凭印象给出条号，必须先在语料中检索确认。

## 六、按问题类型找法

| 问题领域 | 主要法律（语料内） |
| --- | --- |
| 合同、侵权、物权、婚姻家庭、继承 | 民法典 + 对应专门法（如消费者权益保护法、产品质量法） |
| 公司、证券、票据、保险、破产 | 公司法、证券法、票据法、保险法、企业破产法 |
| 行政处罚、行政许可、行政强制 | 行政处罚法、行政许可法、行政强制法 |
| 行政复议、行政诉讼 | 行政复议法、行政诉讼法（诉讼与非诉讼程序法类目） |
| 犯罪与刑罚 | 刑法；程序问题见刑事诉讼法 |
| 劳动关系 | 劳动法、劳动合同法、劳动争议调解仲裁法、社会保险法 |
| 知识产权 | 专利法、商标法、著作权法、反不正当竞争法 |
| 数据与网络 | 网络安全法、数据安全法、个人信息保护法、电子商务法 |
| 生态环境保护 | 生态环境法典（2026-08-15 施行，已整体取代环境保护法及污染防治单行法） |

程序性责任（民事、行政、刑事）分属不同法律，不要用一类法律的条文推断另一类责任。
